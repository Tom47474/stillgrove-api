# Stillgrove 项目实现总结

## 当前代码范围

后端：Java 25 / Spring Boot 4.1 / MyBatis / Flyway / MySQL / Spring Security / Spring Session Redis。前端：React / TypeScript / Vite。AI 使用百炼 OpenAI 兼容 Chat 和 Embedding 接口；记忆正文在 MySQL，向量在 Qdrant。异步任务默认使用 MySQL Outbox 轮询；设置 `ROCKETMQ_ENABLED=true` 后使用 RocketMQ 5 客户端发布和消费。

## 已实现的链路

1. 注册、登录、退出和 `/me`：密码 BCrypt 哈希写入 MySQL，登录态写入 Redis Session，写操作带 CSRF token。登录和注册有 Redis IP 限流。
2. 会话：创建、列表、详情、重命名、软删除。所有操作按当前用户 ID 查询。
3. 消息：按序号分页加载；发送时保存用户消息与待生成助手消息；百炼流式输出通过 SSE 转发；完成或失败时更新消息和 `ai_generations`。
4. 摘要和记忆：回复完成后写 Outbox 事件。后台提取单条长期记忆与会话摘要，保存 MySQL；Embedding 后写 Qdrant。检索先过滤用户，再回 MySQL 验证归属、状态、版本与有效期。未配置外部服务时聊天仍可运行，记忆任务保留待处理。
5. 数据管理：反馈接口、账号注销与 MySQL 内容清理。长期记忆由后台自动提取与保存，用户无需选择保存策略；记忆失效后写删除事件，异步清理 Qdrant 向量。
6. 前端：登录注册、移动端聊天界面、会话列表、历史消息、SSE 流式展示、反馈、设置与注销。

## 后端接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/auth/csrf` | 获取 CSRF token |
| POST | `/api/auth/register`、`/api/auth/login` | 注册、登录 |
| GET / POST | `/api/auth/me`、`/api/auth/logout` | 当前用户、退出 |
| GET / POST | `/api/conversations` | 列表、创建 |
| GET / PATCH / DELETE | `/api/conversations/{id}` | 详情、重命名、删除 |
| GET | `/api/conversations/{id}/messages?before=...` | 消息历史，最多 50 条 |
| POST | `/api/conversations/{id}/messages/stream` | SSE 流式回复，body 为 `content` 与 UUID `requestId` |
| PUT | `/api/messages/{messageId}/feedback` | `HELPFUL` / `NOT_HELPFUL` |
| DELETE | `/api/account` | 验证密码后注销账号 |

## 本地启动

1. 启动 MySQL 和 Redis，确保 Flyway V1～V6 成功。
2. 设置 `DASHSCOPE_API_KEY`。按百炼账号所在地域设置 `DASHSCOPE_BASE_URL`；默认是按量付费兼容地址。可设置 `DASHSCOPE_MODEL`，默认 `qwen-plus`。
3. 启动 Qdrant，并设置 `QDRANT_URL`（默认 `http://localhost:6333`）。Collection 在首次写入时自动创建，向量维度为 1024。
4. 在后端仓库运行 `mvn spring-boot:run`；在前端仓库运行 `npm install`、`npm run dev`。Vite 将 `/api` 代理到 `localhost:8080`。
5. 浏览器打开 Vite 给出的地址。也可按 `doc/注册登录联调.md` 用 Postman 联调。

`ROCKETMQ_ENABLED` 默认为 `false`，本地可直接使用 Outbox 轮询。启用 RocketMQ 时还需提供 RocketMQ 5 Proxy 地址、已创建的 Topic 与 Consumer Group，并设置 `ROCKETMQ_ENDPOINTS`、`ROCKETMQ_TOPIC`、`ROCKETMQ_CONSUMER_GROUP`。

## 生产环境配置

设置 `SPRING_PROFILES_ACTIVE=prod`，并通过环境变量提供 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`、`REDIS_HOST`、`DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL`、`QDRANT_URL`、`STILLGROVE_CORS_ORIGIN` 和 `SESSION_COOKIE_SECURE=true`。前后端需经 HTTPS 访问。不要提交真实密钥或数据库密码。

## 数据流速览

```text
浏览器 → Spring Security/Redis Session → 会话与消息 MySQL
       → 百炼 Chat → SSE → 浏览器
                    ↘ MySQL Outbox → Worker / RocketMQ → 摘要与记忆 MySQL
                                                    ↘ 百炼 Embedding → Qdrant
下次对话 → Qdrant 候选 → MySQL 归属/状态/版本校验 → AI 上下文
```
